# VLM/VLA تکنیکی حوالہ

یہ دستاویز فزیکل ای آئی اور ہیومنوڈ روبوٹکس سسٹم میں وژن-زبان-ماڈل (VLM) اور وژن-زبان-ایکشن (VLA) نفاذ کے بارے میں تفصیلی تکنیکی معلومات فراہم کرتی ہے۔

## سسٹم معماری

### بنیادی اجزاء

VLA سسٹم مندرجہ ذیل بنیادی اجزاء پر مشتمل ہے:

1. **VLA انٹرفیس** (`app/vlm/interface.py`)
   - VLA ماڈلز کے لیے مرکزی انٹرفیس
   - وژن-زبان کی پروسیسنگ کا انتظام
   - روبوٹ ایکشنز تیار کرنا

2. **ROS انٹرفیس** (`app/vlm/ros_interface.py`)
   - VLA سسٹم کو ROS 2 سے جوڑنا
   - جسمانی/سیمولیٹڈ روبوٹس پر ایکشنز انجام دینا
   - روبوٹ کی حالت اور رابطے کا انتظام

3. **کنٹرول انٹرفیس** (`app/vlm/control_interface.py`)
   - بلند سطح کا کنٹرول منطق
   - LLM کوگنیٹو منصوبہ بندی کو روبوٹ ایکشنز سے جوڑنا
   - ایکشن کی توثیق اور انجام دہی کا انتظام

4. **پائپ لائن سسٹم** (`app/vlm/pipeline.py`)
   - مکمل VLA پائپ لائن نفاذ
   - متعدد مراحل کی پروسیسنگ کا انتظام
   - پیچیدہ کام کی ترتیب کا انتظام

5. **API روٹس** (`app/routes/vla.py`)
   - VLA فعالیت کے لیے REST API اینڈ پوائنٹس
   - ویب انٹرفیس کے ساتھ انضمام
   - سیشن کا انتظام

## API اینڈ پوائنٹس

### VLA کمانڈ اینڈ پوائنٹ
```
POST /vla/command
```

**ان پٹ جسم:**
```json
{
  "image": "base64_encoded_image_or_null",
  "language_command": "Natural language command",
  "session_id": "optional_session_id",
  "robot_namespace": "optional_robot_namespace"
}
```

**جواب:**
```json
{
  "success": true,
  "message": "Execution message",
  "session_id": "session_id",
  "actions_executed": [...],
  "execution_time": 2.5,
  "confidence": 0.85
}
```

### VLA کمانڈ تصویر کے ساتھ
```
POST /vla/command-with-image
```

**پیرامیٹر:**
- `language_command`: قدرتی زبان کا حکم
- `image`: فائل اپ لوڈ
- `session_id`: اختیاری سیشن ID
- `robot_namespace`: اختیاری روبوٹ نیم اسپیس

### VLA کمانڈ ترتیب
```
POST /vla/command-sequence
```

**ان پٹ جسم:**
```json
{
  "commands": ["command1", "command2", "command3"],
  "session_id": "optional_session_id",
  "robot_namespace": "optional_robot_namespace"
}
```

### VLA کی حیثیت
```
GET /vla/status
```

**جواب:**
```json
{
  "connected": true,
  "robot_status": {...},
  "pipeline_status": "initialized",
  "active_sessions": 1
}
```

## نفاذ کی تفصیلات

### وژن پروسیسنگ
وژن سسٹم روبوٹ کیمرز سے تصاویر کو پروسیس کرتا ہے تاکہ متعلقہ خصوصیات نکالی جا سکیں:

1. **اشیاء کا پتہ لگانا**: منظر میں اشیاء کی شناخت
2. **جگہ کا ت Reasoning**: اشیاء کے درمیان رشتے کا تعین
3. **خصوصیات نکالنا**: VLA ماڈل کے لیے وژوئل خصوصیات نکالنا

### زبان کی سمجھ
زبان سسٹم قدرتی زبان کے حکم کو پروسیس کرتا ہے:

1. **ارادہ درجہ بندی**: صارف کا ارادہ متعین کرنا
2. **اشیاء نکالنا**: اشیاء، مقامات، اور دیگر اشیاء کی شناخت
3. **سیمینٹک تشریح**: حکم کی ساخت شدہ نمائندگی تخلیق کرنا

### ایکشن منصوبہ بندی
ایکشن منصوبہ بندی سسٹم قابل انجام روبوٹ ایکشنز تیار کرتا ہے:

1. **ایکشن کا انتخاب**: ارادہ کی بنیاد پر مناسب ایکشن کی قسم کا انتخاب
2. **پیرامیٹر تیار کرنا**: ایکشن-مخصوص پیرامیٹر تخلیق کرنا
3. **ترتیب منصوبہ بندی**: متعدد اقدام ایکشن ترتیب کا منصوبہ بند کرنا

### محفوظی کی تصدیق
تمام ایکشنز کو انجام سے پہلے محفوظی کی تصدیق کی جاتی ہے:

1. **کولیژن کا پتہ لگانا**: ممکنہ کولیژن کی جانچ
2. **کنیمیٹک تصدیق**: جوائنٹ کی حدود اور قابل رسائی کی تصدیق
3. **ماحولیاتی محفوظی**: یقین دہانی کرائیں کہ کارروائیاں موجودہ ماحول میں محفوظ ہیں

## کنفیگریشن

### ماحولیاتی متغیرات
VLA سسٹم درج ذیل ماحولیاتی متغیرات کا استعمال کرتا ہے:

- `VLA_MODEL_NAME`: استعمال کرنے کے لیے VLA ماڈل کا نام (ڈیفالٹ: "mobile-vla")
- `VLA_DEVICE`: ماڈل کی انجام دہی کے لیے ڈیوائس (ڈیفالٹ: "cpu")
- `ROS_NAMESPACE`: ROS 2 رابطے کے لیے روبوٹ نیم اسپیس

### ماڈل کنفیگریشن
سسٹم مختلف VLA ماڈل کنفیگریشنز کی حمایت کرتا ہے:

```python
# In app/vlm/interface.py
def _initialize_model(self):
    if self.model_name == "mobile-vla":
        self._initialize_mobile_vla()
    elif self.model_name == "vla-robotics":
        self._initialize_vla_robotics()
    else:
        self._initialize_mock_model()
```

## انضمام کے نقاط

### LLM کوگنیٹو منصوبہ بندی کے ساتھ
VLA سسٹم LLM-مبنی کوگنیٹو منصوبہ بندی کے ساتھ انضمام کرتا ہے:

1. LLM قدرتی زبان سے بلند سطح کے منصوبے تیار کرتا ہے
2. VLA سسٹم منصوبوں کو قابل انجام ایکشنز میں تبدیل کرتا ہے
3. ایکشنز کی تصدیق کی جاتی ہے اور روبوٹ پر انجام دیے جاتے ہیں

### ڈیٹا بیس سسٹم کے ساتھ
تمام VLA تعاملات ڈیٹا بیس میں لاگ کیے جاتے ہیں:

- کمانڈ انجام دہی کی تاریخ
- ایکشن کے نتائج
- سیشن ٹریکنگ
- کارکردگی کے معیار

### چیٹ سسٹم کے ساتھ
VLA سسٹم موجودہ چیٹ سسٹم کے ساتھ انضمام کرتا ہے:

- جب چیٹ سسٹم جسمانی ایکشن کمانڈز کا پتہ لگاتا ہے
- VLA سسٹم جسمانی ایکشنز انجام دیتا ہے
- نتائج چیٹ سسٹم پر واپس رپورٹ کیے جاتے ہیں

## جانچ اور تصدیق

### یونٹ ٹیسٹ
سسٹم میں جامع یونٹ ٹیسٹ شامل ہیں:

- انفرادی اجزاء کی جانچ
- پائپ لائن مرحلہ کی تصدیق
- انضمام کی جانچ
- خامی کا انتظام کی تصدیق

### کارکردگی کی جانچ
کارکردگی کی تصدیق درج ذیل کے ذریعے کی جاتی ہے:

- جواب کے وقت کی پیمائش
- گنجائش کی جانچ
- وسائل کے استعمال کی نگرانی
- حقیقی وقت کی پابندی کی تصدیق

### محفوظی کی جانچ
محفوظی کی تصدیق درج ذیل کے ذریعے کی جاتی ہے:

- محفوظی کی تصدیق سسٹم کی جانچ
- ہنگامی بندش کی طریق کار
- کولیژن سے بچاؤ کی تصدیق
- خامی کی بازیابی کی جانچ

## تنصیب کے امور

### ہارڈ ویئر کی ضروریات
- **CPU**: متوازی پروسیسنگ کے لیے ملٹی-کور پروسیسر
- **GPU**: ماڈل کے اسٹیل کی رفتار کے لیے اختیاری
- **میموری**: ماڈل لوڈنگ اور پروسیسنگ کے لیے کافی RAM
- **نیٹ ورک**: ROS 2 رابطے کے لیے قابل اعتماد کنکشن

### سافٹ ویئر کی انحصاریت
- Python 3.8+
- PyTorch ماڈل انجام دہی کے لیے
- ROS 2 روبوٹ کے رابطے کے لیے
- FastAPI ویب انٹرفیس کے لیے
- Qdrant ویکٹر اسٹوریج کے لیے

### کارکردگی کی بہتری
- کنارے کی تنصیب کے لیے ماڈل کی مقدار
- متوازی کارروائی کے لیے غیر معمولی پروسیسنگ
- اکثر انجام دیئے گئے ایکشنز کے لیے کیش
- حقیقی وقت کی انجام دہی کے لیے وسائل کا انتظام

## مسئلہ حل

### عام مسائل

**مسئلہ**: VLA پائپ لائن شروع نہیں ہوتی
**حل**: ماڈل فائلز اور انحصاریت کی جانچ کریں

**مسئلہ**: روبوٹ کنکشن ناکام ہوتا ہے
**حل**: ROS 2 نیٹ ورک کنفیگریشن کی تصدیق کریں

**مسئلہ**: ایکشن انجام دہی کا وقت ختم ہو جاتا ہے
**حل**: روبوٹ کی دستیابی اور محفوظی کے سسٹم کی جانچ کریں

**مسئلہ**: وژن پروسیسنگ ناکام ہوتی ہے
**حل**: کیمرہ کنکشنز اور اجازت کی تصدیق کریں

### لاگنگ
سسٹم تفصیلی لاگنگ فراہم کرتا ہے:

- پائپ لائن مرحلہ کی انجام دہی
- ایکشن انجام دہی کے نتائج
- خامی کی حالتیں
- کارکردگی کے معیار

### نگرانی
کلیدی معیاروں کی نگرانی کی جاتی ہے:

- پائپ لائن انجام دہی کا وقت
- ایکشن کامیابی کی شرح
- سسٹم وسائل کا استعمال
- خامی کی تعدد

## خاتمہ

VLA سسٹم ہیومنوڈ روبوٹکس سسٹم کے ساتھ وژن-زبان-ایکشن ماڈلز کو ضم کرنے کے لیے ایک جامع فریم ورک فراہم کرتا ہے۔ ماڈیولر معماری آسان توسیع اور دیکھ بھال کو فعال کرتی ہے جبکہ حقیقی دنیا کی تنصیب میں محفوظی اور قابل اعتمادی کو یقینی بناتی ہے۔
