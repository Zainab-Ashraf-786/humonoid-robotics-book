# فوٹو ریلٹسٹک سمیولیشن کے لیے NVIDIA Isaac Sim

NVIDIA Isaac Sim NVIDIA Omniverse پلیٹ فارم پر تعمیر شدہ نسل کے بعد کا روبوٹکس سمولیٹر ہے۔ یہ فوٹو ریلٹسٹک سمیولیشن، مصنوعی ڈیٹا سیٹ جنریشن، اور GPU-تیز فزکس سمیولیشن کی صلاحیتیں فراہم کرتا ہے جو روبوٹکس ایپلی کیشنز میں AI سسٹم کی تربیت کے لیے ضروری ہیں۔

## سیکھنے کے اہداف

اس سیکشن کو مکمل کرنے کے بعد، آپ کر سکیں گے:
- Isaac Sim کی آرکیٹیکچر اور صلاحیتیں کو سمجھنا
- Isaac Sim ماحول کو تخلیق اور تشکیل دینا
- AI تربیت کے لیے مصنوعی ڈیٹا سیٹس کو تخلیق کرنا
- Isaac Sim اور Isaac ROS کے درمیان انضمام سے واقف ہونا
- تصوراتی سینسرز کی توثیق کرنا کہ وہ حقیقی دنیا کے ہم مند سے مماثل ہیں

## Isaac Sim کا تعارف

### Isaac Sim کیا ہے؟

Isaac Sim NVIDIA کا جدید روبوٹکس سمولیٹر ہے جو خاص طور پر مندرجہ ذیل کے لیے ڈیزائن کیا گیا ہے:
- **فوٹو ریلٹسٹک سمیولیشن**: ادراک کی تربیت کے لیے بصری طور پر حقیقی ماحول تخلیق کرنا
- **مصنوعی ڈیٹا سیٹ جنریشن**: AI ماڈلز کے لیے بڑے پیمانے پر تربیتی ڈیٹا تیار کرنا
- **الگوری دم کی جانچ**: محفوظ ورچوئل ماحول میں ادراک اور نیویگیشن الگوری دم کی توثیق
- **ہارڈ ویئر تیزی**: مؤثر سمیولیشن کے لیے NVIDIA GPU کا استعمال
- **Omniverse انضمام**: NVIDIA کے 3D ڈیزائن پلیٹ فارم کے ساتھ بے دریغ رابطہ

### کلیدی خصوصیات

1. **PhysX GPU تیزی**: ہارڈ ویئر-تیز فزکس سمیولیشن
2. **RTX رے ٹریسنگ**: گلوبل ایلومینیشن کے ساتھ فوٹو ریلٹسٹک رینڈرنگ
3. **مصنوعی ڈیٹا جنریشن**: لیبل والے تربیتی ڈیٹا سیٹس تخلیق کرنے کے لیے ٹولز
4. **ROS/ROS 2 برج**: روبوٹکس مڈل ویئر کے ساتھ براہ راست انضمام
5. **ماڈیولر آرکیٹیکچر**: حسب ضرورت سینسرز، روبوٹس، اور ماحول کی حمایت

### Isaac Sim بمقابلہ روایتی سمولیٹر

ماڈیول 2 میں ذکر کردہ روایتی سمولیٹر جیسے گزیبو کے مقابلے میں:

| خصوصیت | گزیبو | Isaac Sim |
|---------|--------|-----------|
| بصری معیار | اچھا جیومیٹرک درستگی | رے ٹریسنگ کے ساتھ فوٹو ریلٹسٹک |
| فزکس انجن | ODE، بُلیٹ، DART | PhysX کے ساتھ GPU تیزی |
| سینسر سمیولیشن | فزکس-مبنی | فزکس + ظہور-مبنی |
| AI تربیت کا مرکز | جنرل روبوٹکس ترقی | AI/ML تربیت اور توثیق |
| مصنوعی ڈیٹا | محدود صلاحیتیں | جامع جنریشن ٹولز |
| GPU تیزی | محدود | وسیع (RTX/PhysX) |

## Isaac Sim کو انسٹال کرنا اور سیٹ اپ کرنا

### سسٹم کی ضروریات

**کم از کم ضروریات:**
- OS: Ubuntu 20.04/22.04 یا Windows 10/11
- CPU: Intel/AMD ملٹی-کور پروسیسر
- RAM: 16GB کم از کم (32GB تجویز کردہ)
- GPU: NVIDIA RTX سیریز (کم از کم RTX 3060 کے ساتھ 8GB+ VRAM)
- اسٹوریج: 10GB دستیاب جگہ
- نیٹ ورک: ابتدائی ڈاؤن لوڈ کے لیے انٹرنیٹ رسائی

**تجویز کردہ ضروریات:**
- GPU: RTX 4080/4090 یا مساوی کے ساتھ 16GB+ VRAM
- RAM: 32GB یا زیادہ
- SSD اسٹوریج تیز اثاثہ لوڈنگ کے لیے

### انسٹالیشن عمل

1. **NVIDIA ڈرائیورز انسٹال کریں**: یقین کریں کہ Isaac Sim کے ساتھ مطابقت رکھنے والے تازہ ترین NVIDIA ڈرائیورز ہیں
2. **Isaac Sim ڈاؤن لوڈ کریں**: NVIDIA ڈیویلپر پروگرام کے ذریعے دستیاب
3. **Isaac Sim انسٹال کریں**: اپنے پلیٹ فارم کے لیے NVIDIA کے انسٹالیشن گائیڈ کو فالو کریں
4. **Isaac ROS برج انسٹال کریں**: اگر ROS/ROS 2 انضمام استعمال کر رہے ہوں
5. **انسٹالیشن کی توثیق کریں**: ایک سادہ ٹیسٹ ماحول چلائیں

### ابتدائی کنفیگریشن

انسٹالیشن کے بعد، اپنے روبوٹکس پروجیکٹس کے لیے Isaac Sim کو تشکیل دیں:

```bash

```

## Isaac Sim ماحول تخلیق کرنا

### منظر کی تعمیر

Isaac Sim منظر کی تعمیر کے لیے Omniverse کے USD (یونیورسل سین ڈسکرپشن) فارمیٹ کا استعمال کرتا ہے۔ گزیبو کے SDF فارمیٹ کے برعکس، USD پیچیدہ مواد، لائٹنگ، اور جدید رینڈرنگ کی حمایت فراہم کرتا ہے:

```python
# Isaac Sim میں Python API کا استعمال کرتے ہوئے ایک سادہ منظر تخلیق کرنے کی مثال
import omni
from pxr import UsdGeom, Gf, UsdLux

# ایک نیا اسٹیج بنائیں
stage = omni.usd.get_context().get_stage()

# دنیا کا prim بنائیں
world_prim = UsdGeom.Xform.Define(stage, "/World")

# ایک زمینی سطح شامل کریں
plane_prim = UsdGeom.Mesh.Define(stage, "/World/GroundPlane")
# سطح کی خصوصیات کو تشکیل دیں (vertices، normals، وغیرہ)

# لائٹنگ شامل کریں
light_prim = UsdLux.DistantLight.Define(stage, "/World/Light")
light_prim.CreateIntensityAttr(3000)
```

## Isaac Sim میں سینسر سمیولیشن

### فوٹو ریلٹسٹک کیمرہ سینسرز

Module 2 میں دیکھے گئے گزیبو کی بنیادی کیمرہ سمیولیشن کے برعکس، Isaac Sim فراہم کرتا ہے:
- **RTX رے ٹریسنگ**: حقیقی لائٹنگ اور سایوں
- **جسمانی-مبنی شیڈرز**: درست مادہ کا ظہور
- **کیمرہ ماڈلز**: DSLR، pinhole، fisheye، سٹیریو ترتیبات
- **ڈسٹورشن ماڈلز**: حقیقی لینس ڈسٹورشن سمیولیشن

```python
# مثال: Isaac Sim میں ایک فوٹو ریلٹسٹک کیمرہ کو تشکیل دینا
from omni.isaac.core.utils.prims import define_prim
from omni.isaac.sensor import Camera

# کیمرہ prim بنائیں
camera_path = "/World/Robot/Camera"
define_prim(camera_path, "Camera")

# کیمرہ کی خصوصیات کو تشکیل دیں
camera = Camera(
    prim_path=camera_path,
    frequency=30,
    resolution=(640, 480),
    position=Gf.Vec3d(0.2, 0, 0.8),  # 20cm آگے، 80cm اونچا
    orientation=Gf.Quatd(1, 0, 0, 0)  # کوئی گھمائی نہیں
)

# فوٹو ریلٹسٹک رینڈرنگ کے لیے تشکیل دیں
camera.set_postproc_settings({
    "exposure": 0.02,  # 1/50s ایکسپوزر
    "fstop": 2.8,      # ایپرچر سیٹنگ
    "iso": 100,        # ISO حساسیت
    "distortion_k1": -0.15,  # ردیل ڈسٹورشن
})
```

## ہیومنائڈ روبوٹکس کے لیے Isaac Sim

### ہیومنائڈ-مخصوص سمیولیشن خصوصیات

Isaac Sim ہیومنائڈ روبوٹکس کے لیے خاص طور پر قیمتی خصوصیات فراہم کرتا ہے:

1. **پیچیدہ ارٹیکولیشن**: بہت سے ڈگریز آف فریڈم کی حمایت
2. **بیلنس سمیولیشن**: مرکز کی درست توازن اور فزکس
3. **لیمب انٹرایکشن**: حقیقی لیمب-ماحول کے تعاملات
4. **وہول بائڈی کنٹرول**: پیچیدہ وہول-بائڈی کنٹرولرز کی حمایت
5. **گیٹ سمیولیشن**: فزکس-مبنی چلنا اور لوموشن

### ہیومنائڈز کے لیے فزکس کے مسائل

Isaac Sim میں ہیومنائڈ روبوٹس کی سمیولیشن کرتے وقت:
- **ماس تقسیم**: مرکز کی درست توازن کی نمائندگی
- **پاؤں کا رابطہ**: مستحکم کھڑے ہونے کے لیے مناسب متعدد نکاتی رابطہ
- **ایکچو ایٹر ڈائنامکس**: حقیقی جوڑ کی مطیعیت اور ردعمل
- **سینسنگ**: درست IMU اور پروپریوسیپٹو سینسنگ

### مثال ہیومنائڈ منظر: توازن

```python
# مثال: Isaac Sim میں ہیومنائڈ توازن سمیولیشن
import omni
from omni.isaac.core import World
from omni.isaac.core.robots import Robot
from omni.isaac.core.utils.stage import add_reference_to_stage

# دنیا کو سیٹ اپ کریں
world = World(stage_units_in_meters=1.0)

# ہیومنائڈ روبوٹ شامل کریں
humanoid_asset_path = "path/to/humanoid.usd"
add_reference_to_stage(usd_path=humanoid_asset_path, prim_path="/World/Humanoid")
humanoid = world.scene.add(Robot(prim_path="/World/Humanoid", name="humanoid"))

# توازن کنٹرول سمیولیشن سیٹ اپ کریں
# ... کنٹرول نفاذ ...

# فزکس اور رینڈرنگ کے ساتھ سمیولیشن چلائیں
for i in range(10000):
    world.step(render=True)

    # سینسر ڈیٹا حاصل کریں
    joint_positions = humanoid.get_joints_state().positions
    imu_data = get_imu_data()  # IMU پڑھنے کے لیے حسب ضرورت فنکشن

    # کنٹرول لاگو کریں
    control_signals = balance_controller.compute(joint_positions, imu_data)
```

## Isaac Sim کے لیے بہترین طریقے

### کارکردگی کی بہتری

1. **تفصیل کا درجہ (LOD)**: جب سینسرز سے دور ہوں تو سادہ ماڈلز استعمال کریں
2. **کلینگ**: سینسرز کے لیے غیر مرئی اشیاء کو رینڈر نہ کریں
3. **فزکس کی سادگی**: مناسب جگہوں پر سادہ کولیژن جیومیٹریز استعمال کریں
4. **رینڈر سیٹنگز**: درکار معیار بمقابلہ کارکردگی کی بنیاد پر RTX سیٹنگز ایڈجسٹ کریں
5. **بیچ پروسیسنگ**: بڑے ڈیٹا سیٹس کو حقیقی وقت کے بجائے بیچ میں تیار کریں

### معیار کی توثیق

1. **حقیقت چیک**: مصنوعی ڈیٹا کو حقیقی دنیا کے ہم مند کے ساتھ موازنہ کریں
2. **اعداد و شمار کی توثیق**: یقین کریں کہ مصنوعی ڈیٹا سیٹس حقیقی دنیا کے تقسیم سے مماثل ہیں
3. **ڈومین گیپ کا جائزہ**: مصنوعی اور حقیقی ڈیٹا کے درمیان کارکردگی کے فرق کو پیمائیں
4. **سینسر کی توثیق**: یقین کریں کہ تصوراتی سینسرز حقیقی سینسر کی خصوصیات سے مماثل ہیں

### عام مسائل کا حل

1. **کارکردگی کے مسائل**:
   - GPU استعمال اور VRAM استعمال چیک کریں
   - جہاں ممکن ہو منظر کی پیچیدگی کو آسان کریں
   - رینڈرنگ کے معیار کی ترتیبات ایڈجسٹ کریں
   - اگر حقیقی وقت میں ضرورت نہ ہو تو سمیولیشن کی فریکوئنسی کم کریں

2. **فزکس عدم استحکام**:
   - ماس اور انیشیل خصوصیات کی تصدیق کریں
   - جوڑ کی حدیں اور قیود چیک کریں
   - فزکس حل کنندہ پیرامیٹر ایڈجسٹ کریں
   - کولیژن مش کے معیار کی تصدیق کریں

3. **رینڈرنگ آرٹیفیکٹس**:
   - مادہ کی خصوصیات کی تصدیق کریں
   - لائٹنگ کنفیگریشن چیک کریں
   - کیمرہ کے پیرامیٹر کی تصدیق کریں
   - مناسب طریقے سے RTX سیٹنگز ایڈجسٹ کریں

## پچھلے ماڈیولز سے ربط

Isaac Sim پچھلے ماڈیولز کے تصورات پر تعمیر کرتا ہے:
- **ماڈیول 1 (ROS 2)**: سینسر ڈیٹا اور کنٹرول کے لیے ROS/ROS 2 رابطہ کے نمونوں کو استعمال کرتا ہے
- **ماڈیول 2 (سمیولیشن)**: فوٹو ریلٹسٹک معیار کے ساتھ جدید سمیولیشن پیش کرتا ہے جو فزکس-مرکز گزیبو کو مکمل کرتا ہے

## اگلے اقدامات

فوٹو ریلٹسٹک سمیولیشن کے لیے Isaac Sim کو سمجھنے کے بعد، اگلا سیکشن [Isaac ROS for Perception and Navigation](./isaac-ros) پر ہے، جہاں آپ سیکھیں گے کہ یہ تصوراتی سینسرز حقیقی AI ادراک اور نیویگیشن سسٹم سے کیسے منسلک ہوتے ہیں۔

## خلاصہ

Isaac Sim روبوٹکس سمیولیشن میں ایک اہم ترقی کی نمائندگی کرتا ہے، مصنوعی ڈیٹا سیٹ جنریشن اور معیاری بصری سمیولیشن کے لیے فوٹو ریلٹسٹک رینڈرنگ کی صلاحیتیں فراہم کرتا ہے۔ Isaac ROS کے ساتھ اس کا انضمام سمیولیشن اور حقیقی دنیا کے روبوٹکس ایپلی کیشنز کے درمیان بے دریغ منتقلی کو فعال کرتا ہے۔ یہ پلیٹ فارم خاص طور پر ہیومنائڈ روبوٹکس کے لیے قیمتی ہے جہاں حقیقی ادراک اور فزکس AI کی کامیاب تربیت اور توثیق کے لیے اہم ہیں۔
