# تکنیکی ضروریات

یہ دستاویز فزیکل اے آئی اور ہیومنائڈ روبوٹکس کورس کے ہر ماڈیول کے لیے تکنیکی ضروریات کا خاکہ پیش کرتی ہے۔

## سسٹم کی ضروریات

### کم از کم سسٹم تفصیلات
- **آپریٹنگ سسٹم**: Windows 10/11، Ubuntu 20.04/22.04، یا macOS 10.15+
- **CPU**: ملٹی-کور پروسیسر (Intel i5 یا اس کے مساوی تجویز کردہ)
- **RAM**: 8GB کم از کم، 16GB تجویز کردہ
- **اسٹوریج**: مکمل کورس کے لیے 50GB خالی جگہ
- **گرافکس**: بنیادی سمیولیشن کے لیے انٹیگریٹڈ گرافکس؛ اعلیٰ درجے کی رینڈرنگ کے لیے 4GB+ VRAM کے ساتھ ڈیڈیکٹیڈ GPU
- **نیٹ ورک**: پیکجوں کے ڈاؤن لوڈ اور دستاویزات کے لیے انٹرنیٹ رسائی

### تجویز کردہ ترقی کا ماحول
- **IDE/ایڈیٹر**: ہر ٹیکنالوجی کے لیے مناسب ایکسٹینشنز کے ساتھ VS Code
- **ٹرمنل**: PowerShell (Windows)، ٹرمنل (macOS)، یا ترجیحی Linux ٹرمنل
- **Git**: ورژن 2.30 یا اس سے زیادہ
- **Docker**: کنٹینرائزڈ ماحول استعمال کرتے وقت

## ماڈیول-مخصوص ضروریات

### ماڈیول 1: روبوٹک نروس سسٹم (ROS 2)

#### سافٹ ویئر کی ضروریات
- **ROS 2**: Humble Hawksbill (موجودہ LTS ورژن)
- **Python**: 3.8 یا اس سے زیادہ
- **Build System**: CMake 3.12 یا اس سے زیادہ
- **کمپائلر**: GCC 9 یا اس سے زیادہ (Linux)، Visual Studio 2019 یا اس سے زیادہ (Windows)

#### OS-مخصوص سیٹ اپ
- **Linux (Ubuntu)**:
  - یونیورس، ملٹی ورس، اور ری سٹرکٹڈ کے لیے ریپوزیٹری رسائی فعال
  - ریل ٹائم کرنل (اختیاری، کارکردگی کے لیے اہم ایپلی کیشنز کے لیے)
- **Windows**:
  - Ubuntu ڈسٹری بیوشن کے ساتھ WSL2 تجویز کردہ
  - C++ ترقی کے اوزار کے ساتھ Visual Studio
- **macOS**:
  - Xcode کمانڈ لائن ٹولز

#### ترقی کے اوزار
- **ٹیکسٹ ایڈیٹر**: ROS ایکسٹینشن کے ساتھ VS Code
- **ورژن کنٹرول**: Git Bash (Windows) کے ساتھ Git
- **پیکج مینیجر**: APT (Ubuntu)، Chocolatey (Windows)، Homebrew (macOS)

### ماڈیول 2: ڈیجیٹل ٹوئن (گزیبو اور یونٹی)

#### گزیبو کی ضروریات
- **گزیبو ورژن**: گارڈن یا مطابقت رکھنے والا ورژن
- **فزکس انجن**: ODE، بُلیٹ، یا DART (گزیبو کے ساتھ پہلے سے انسٹال)
- **گرافکس**: OpenGL 3.3+ کے مطابق گرافکس کارڈ
- **GPU**: 2GB VRAM کے ساتھ ڈیڈیکٹیڈ GPU تجویز کردہ

#### یونٹی کی ضروریات
- **یونٹی ہب**: موجودہ ورژن
- **یونٹی ایڈیٹر**: 2021.3 LTS یا نیا ورژن
- **یونٹی پیکجوں**:
  - یونیورسل رینڈر پائپ لائن (URP) یا ہائی ڈیفینیشن رینڈر پائپ لائن (HDRP)
  - یونٹی روبوٹکس پیکج
  - ML-ایجنٹس ٹول کٹ (اختیاری)

#### سمولیشن ماحول
- **میموری**: پیچیدہ سمولیشن کے لیے 4GB RAM مزید
- **اسٹوریج**: سمولیشن اثاثوں کے لیے 10GB اضافی جگہ
- **GPU**: 4GB+ VRAM کے ساتھ ڈیڈیکٹیڈ GPU اعلیٰ معیار کی رینڈرنگ کے لیے

### ماڈیول 3: اے آئی - روبوٹ براہین (NVIDIA Isaac™)

#### ہارڈ ویئر کی ضروریات
- **GPU**: کمپیوٹ کی صلاحیت 6.0 یا اس سے زیادہ کے ساتھ NVIDIA GPU
- **VRAM**: پیچیدہ اے آئی ماڈلز کے لیے 8GB+ تجویز کردہ
- **CUDA**: CUDA 11.8 یا اس سے زیادہ

#### سافٹ ویئر کی ضروریات
- **NVIDIA Isaac Sim**: Omniverse کے ساتھ مطابقت رکھنے والا موجودہ ورژن
- **Isaac ROS**: تازہ ترین مستحکم ریلیز
- **Isaac Apps**: حوالہ نفاذ کے لیے
- **Docker**: کنٹینرائزڈ Isaac ایپلی کیشنز کے لیے
- **NVIDIA Container Runtime**: GPU-ایکسلریٹڈ کنٹینرز کے لیے

#### ترقی کی وابستگیاں
- **Python**: Isaac-مخصوص پیکجوں کے ساتھ 3.8 یا اس سے زیادہ
- **OpenCV**: کمپیوٹر وژن کے کاموں کے لیے
- **TensorFlow/PyTorch**: نیورل نیٹ ورک کے نفاذ کے لیے
- **ROS 2**: Isaac اجزاء کے ساتھ انٹیگریشن

### ماڈیول 4: فزیکل اے آئی اور ہیومنائڈ روبوٹکس (کیپسٹون)

#### انٹیگریشن کی ضروریات
- **تمام پچھلے ماڈیول کی ضروریات** کو پورا کرنا لازمی ہے اور کام کرنا چاہیے
- **سسٹم میموری**: ایک ساتھ متعدد سسٹم چلانے کے لیے 16GB+ تجویز کردہ
- **اسٹوریج**: کیپسٹون پروجیکٹ اثاثوں کے لیے 20GB اضافی

#### اضافی اوزار
- **کنٹرول سسٹم**: جسمانی روبوٹ کے انٹیگریشن کے لیے ریل ٹائم قابل سسٹم (اگر لاگو ہو)
- **سینسر سمولیشن**: تمام سینسر کی اقسام کے لیے سپورٹ جو پچھلے ماڈیولز میں احاطہ کیا گیا
- **کارکردگی کی پروفائلنگ**: روبوٹ سسٹم کی کارکردگی کو بہتر بنانے کے لیے اوزار

## نیٹ ورک اور بیرونی وابستگیاں

### انٹرنیٹ کی ضروریات
- **بینڈ وڈتھ**: پیکجوں کے ڈاؤن لوڈ کے لیے 10 Mbps کم از کم
- **رسائی**: پیکج ریپوزیٹریز (ROS، npm، pip، یونٹی اثاثہ اسٹور) تک غیر محدود رسائی
- **فائر وال**: Docker کنٹینرز اور ROS نیٹ ورک مواصلات کی اجازت دینے کے لیے کنفیگریشن

### بیرونی خدمات
- **GitHub**: کورس کے مواد اور کوڈ کی مثالوں کے لیے
- **Docker Hub**: کنٹینرائزڈ روبوٹکس ایپلی کیشنز کے لیے
- **NVIDIA Developer**: Isaac-مخصوص وسائل کے لیے
- **ROS Index**: پیکج کی دریافت اور دستاویزات کے لیے

## ٹیسٹنگ اور توثیق

### ضروریات کی تصدیق
ہر ماڈیول شروع کرنے سے پہلے، اس بات کو یقینی بنائیں کہ آپ کا سسٹم ضروریات پوری کرتا ہے:
1. سسٹم ڈائیگنوسٹک اسکرپٹس چلائیں (ہر ماڈیول میں فراہم کردہ)
2. ماحولیاتی متغیرات درست طریقے سے سیٹ ہیں کیا تصدیق کریں
3. کور ٹولز کی بنیادی کارکردگی کو ٹیسٹ کریں
4. ہارڈ ویئر کی مطابقت کی تصدیق کریں

### کارکردگی کے معیار
- **سمولیشن**: بنیادی منظار کے لیے 60+ FPS پر چلنا چاہیے
- **AI Inference**: مخصوص وقت کی حد کے اندر مکمل ہونا چاہیے
- **ROS Communication**: کم تاخیر برقرار رکھنا چاہیے (100ms سے کم)

## عام مسائل کا حل

### انسٹالیشن کے مسائل
- انسٹالیشن سے پہلے سسٹم کی مطابقت چیک کریں
- انٹرنیٹ کنیکٹویٹی اور پراکسی ترتیبات کی تصدیق کریں
- کافی ڈسک کی جگہ اور اجازتیں ہونے کو یقینی بنائیں

### کارکردگی کے مسائل
- غیر ضروری ایپلی کیشنز بند کریں
- GPU ڈرائیورز اپ ٹو ڈیٹ ہیں کیا تصدیق کریں
- ضرورت پڑنے پر سمولیشن کی معیار کی ترتیبات ایڈجسٹ کریں

ماڈیول-مخصوص حل کے لیے، متعلقہ ماڈیول کی دستاویزات کو دیکھیں۔
