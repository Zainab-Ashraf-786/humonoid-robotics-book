# Course Modules

This page provides an overview of the four comprehensive modules in our Physical AI & Humanoid Robotics course. Each module builds upon the previous one to create a complete learning path from fundamental robotics concepts to advanced AI integration.

## Module 1: The Robotic Nervous System (ROS 2)

**Module Number:** 01
**Focus:** ROS 2 fundamentals, nodes, topics, services, and Python integration
**Description:** Master the core communication patterns that form the backbone of robotic systems. Learn how nodes interact through topics, services, and actions.

[Learn More About Module 1](./ros2-fundamentals)

## Module 2: The Digital Twin (Gazebo & Unity)

**Module Number:** 02
**Focus:** Physics simulation, Gazebo, Unity, and sensor simulation
**Description:** Understand how to create realistic simulation environments for testing and validating robotic systems. Explore both physics-accurate and visually-rich simulation approaches.

[Learn More About Module 2](./digital-twin-sim)

## Module 3: The AI-Robot Brain (NVIDIA Isaac™)

**Module Number:** 03
**Focus:** Isaac Sim, Isaac ROS, perception, and navigation
**Description:** Dive into AI-driven perception and navigation systems using NVIDIA's Isaac platform. Learn how to integrate advanced AI capabilities with robotic systems.

[Learn More About Module 3](./isaac-ai-brain)

## Module 4: Physical AI & Humanoid Robotics (Capstone)

**Module Number:** 04
**Focus:** Physical AI principles, embodied intelligence, LLM cognitive planning
**Description:** The capstone module that integrates all previous concepts into complete humanoid robotics systems. Apply Physical AI principles to create embodied intelligence.

[Learn More About Module 4](./physical-ai-hr)
