# Physical AI & Humanoid Robotics Course

Welcome to the comprehensive Physical AI & Humanoid Robotics course! This 4-module sequence will take you from ROS 2 fundamentals through advanced AI integration for humanoid robots.

## Course Overview

This course is structured into 4 progressive modules that build upon each other to provide a complete understanding of Physical AI and humanoid robotics:

1. **[Module 1: The Robotic Nervous System (ROS 2)](/docs/ros2-fundamentals)** - Foundation in ROS 2 concepts, communication patterns, and Python integration
2. **[Module 2: The Digital Twin (Gazebo & Unity)](/docs/digital-twin-sim)** - Physics simulation, Gazebo, Unity, and sensor simulation 
3. **[Module 3: The AI-Robot Brain (NVIDIA Isaac™)](/docs/isaac-ai-brain)** - Isaac Sim, Isaac ROS, perception, and navigation
4. **[Module 4: Physical AI & Humanoid Robotics (Capstone)](/docs/physical-ai-hr)** - Integration of all previous concepts in humanoid robotics

## Learning Path

Each module is designed to be completed in sequence, with each building on the knowledge from the previous modules. This approach ensures you develop a solid foundation before moving to more advanced topics.

### Prerequisites

- Basic programming knowledge (Python preferred)
- Understanding of fundamental robotics concepts
- Access to appropriate computing resources for simulation

## What You'll Learn

By the end of this course, you will be able to:
- Master ROS 2 as a robot middleware system
- Create and simulate complex robotic systems with Gazebo and Unity
- Implement AI-driven perception and navigation with NVIDIA Isaac
- Integrate Physical AI and embodied intelligence in humanoid robots
- Build complete humanoid robot systems combining all technologies
- Understand the complete pipeline from simulation to deployment

## Getting Started

Begin with **[Module 1: The Robotic Nervous System (ROS 2)](/docs/ros2-fundamentals)** to establish your foundational knowledge. Each module contains multiple sections that progressively build your understanding and skills.
